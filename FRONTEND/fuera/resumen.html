Volver al inicio

HTML define el contenido. CSS cambia su apariencia. Esta página no tiene estilos de presentación; solo los ejemplos de CSS usan los estilos que se muestran en su código.

Etiquetas y atributos

  • <head>: información de la página; no es el contenido visible.
  • <title>: nombre de la pestaña del navegador.
  • <body>: contenido visible de la página.
  • <h1> a <h6>: niveles de títulos.
  • <nav>: agrupa enlaces de navegación.
  • <main>: contiene el contenido principal.
  • <img src="foto.jpg" alt="Descripción">: muestra una imagen; el archivo debe existir.
  • <pre>: conserva espacios y saltos de línea.
  • <code>: identifica texto como código.
  • <table>: tabla; <tr>: fila; <th>: encabezado; <td>: celda. Así se comparan el código y el resultado en esta página.
  • class="tarjeta": permite compartir estilos. En CSS se selecciona con .tarjeta.
  • id="eventos": identifica un elemento; debe ser único en la página.
  • style="...": aplica CSS directamente a un elemento.

Para mostrar etiquetas como texto se escribe &lt; para < y &gt; para >.

Titulos y parrafos

h1 es el título principal; h2, un título de sección; p, un párrafo. 

<h2>Titulowsky</h2>
<p>bipbop.</p>

Titulowsky

bipbop

Texto importante

strong marca en negrita.

<p>Recuerda <strong>revisar la fecha</strong>.</p>

Recuerda revisar la fecha.

Enlace

a crea un enlace. href indica el archivo que se abrirá.

<a href="index.html">Volver al inicio</a>
 Volver al inicio

Lista con viñetas

ul crea la lista y cada li es un elemento.

<ul>
    <li>Eventos</li>
    <li>Categorías</li>
</ul>
  • Eventos
  • Categorías

Lista numerada

ol numera automáticamente los elementos li.

<ol>
    <li>Elegir evento</li>
    <li>Revisar información</li>
</ol>
  1. Elegir evento
  2. Revisar información

Agrupar contenido

section agrupa un tema. div es un contenedor genérico. Por sí solos no dibujan cuadros. 

<section>
    <h3>Eventos</h3>
    <p>Información del evento.</p>
</section>

Botón

button crea un botón. Este ejemplo no tiene una acción programada; para navegar usa a. 

<button type="button">Mi botón</button>

Cuadro con borde

CSS se escribe como propiedad: valor;. border define el borde y padding deja espacio interior. 

<div style="border: 1px solid black; padding: 16px;">
    Mi cuadro
</div>
Mi cuadro

Ancho y alto

width es el ancho y height es el alto. px significa píxeles. border-box incluye borde y relleno en esas medidas. 

<div style="width: 200px; height: 100px;
    box-sizing: border-box; border: 1px solid black;">
    Cuadro de 200 × 100 píxeles
</div>
Cuadro de 200 × 100 píxeles

Alto mínimo

min-height permite que el cuadro crezca si agregas más contenido. 

<div style="width: 200px; min-height: 80px;
    border: 1px solid black;">
    Puedo crecer si necesito más espacio.
</div>
Puedo crecer si necesito más espacio.

Espacio interior y exterior

padding separa el contenido del borde. margin separa el cuadro de lo que lo rodea. 

<div style="border: 1px solid black;">
    <div style="margin: 20px; padding: 16px;
        border: 1px solid gray;">
        Contenido
    </div>
</div>
Contenido

Esquinas redondeadas

border-radius redondea las esquinas. Un ancho y alto iguales forman un cuadrado. 

<div style="width: 100px; height: 100px;
    border: 1px solid black; border-radius: 12px;">
</div>

Círculo

Con el mismo ancho y alto, border-radius: 50% forma un círculo. 

<div style="width: 100px; height: 100px;
    border: 1px solid black; border-radius: 50%;">
</div>

Color y texto

color cambia el texto; background-color, el fondo; font-size, el tamaño; text-align, la alineación del texto. 

<p style="color: blue; background-color: lightgray;
    font-size: 24px; text-align: center;">
    Ticketuki
</p>

Ticketuki

Cuadros juntos

display: flex coloca los elementos en una fila. gap los separa y flex-wrap permite otra fila si no caben. 

<div style="display: flex; gap: 16px; flex-wrap: wrap;">
    <div style="border: 1px solid black; padding: 12px;">
        Eventos
    </div>
    <div style="border: 1px solid black; padding: 12px;">
        Categorías
    </div>
</div>
